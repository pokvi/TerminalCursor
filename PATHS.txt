 ------------------------------------------------------------------------
  ТЕСТЫ / ЗАПУСК ИГРЫ — ТОЛЬКО ЧЕРЕЗ test.bat (инструкция для AI-агента)
------------------------------------------------------------------------
AI-агент обязан проверять мод ИСКЛЮЧИТЕЛЬНО запуском test.bat из корня
репозитория. НЕ запускать игру вручную, НЕ писать свои .ps1/.py для
запуска игры, НЕ читать логи по кусочкам своими командами.

  cd D:\.code\pokvi_code\TerminalCursor
  .\test.bat 90          <- 90 = сколько секунд дать игре поработать

Батник делает весь цикл сам:
  1. убивает запущенную игру (иначе dll в папке модов залочена и не
     перезапишется — на этом спотыкались уже дважды)
  2. dotnet build -c Release: при ЛЮБОЙ ошибке компиляции сразу выход с
     кодом 1, игру не трогает, плагин не перезаписывает
  3. кладёт свежий TerminalMouse.dll в BepInEx\plugins\TerminalMouse\
     (сверка по hash; если залочено — переименовывает старый и пишет
     новый; не вышло — выход с кодом 2, дальше ничего не проверяем)
  4. удаляет старые логи и запускает игру со своим -logFile
  5. ждёт N секунд; если игра умерла раньше — это краш, пишет об этом
  6. УБИВАЕТ игру и сам печатает: строки мода и ошибки из LogOutput.log,
     строки мода из Player.log и последние 30 строк Player.log

Коды возврата: 0 = прогон состоялся, 1 = ошибка сборки, 2 = dll не легла.
Полные копии логов после прогона лежат в подпапке terminalmouse_test
внутри %TEMP% (LogOutput.last.log и Player.log).
